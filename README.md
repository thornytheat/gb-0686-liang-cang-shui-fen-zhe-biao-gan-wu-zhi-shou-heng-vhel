# 粮仓水分折标与干物质守恒

使用者：粮库结算员。接收多车次化验与地磅文件，复核折标数量后向财务结算。

核心规则：保留干物质：标准重量=净重×(1-实测水分)/(1-标准水分)，杂质先扣，超限退收，舍入只在结算末端。

## 启动

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

浏览器访问 http://localhost:18200 。首页已装载脏样例，可编辑CSV与参数后运行，也可上传文件。七个导航分别对应业务步骤。

## 模块

- M1 磅单接收：接收磅单并检查结构，入口 `/m/1`、`GET/POST /api/m1`。
- M2 水杂契约：校核水杂和单位，入口 `/m/2`、`GET/POST /api/m2`。
- M3 折标计算：扣杂后按干物质折标，入口 `/m/3`、`GET/POST /api/m3`。
- M4 车次归并：按版本裁决冲突磅单，入口 `/m/4`、`GET/POST /api/m4`。
- M5 仓批平衡：逐仓核对干物质平衡，入口 `/m/5`、`GET/POST /api/m5`。
- M6 结算复核：结算到分并保留尾差依据，入口 `/m/6`、`GET/POST /api/m6`。
- M7 批次追溯：检查行数平衡与证据摘要，入口 `/m/7`、`GET/POST /api/m7`。
- M8 定等应付：按水分杂质定等，单车一结论计价，混仓重算与应付锁单，入口 `/grading`。

## 定等应付（M8）

收购合同按水分和杂质定等，粮车进库当天出等级、折标量与应付。与 M1–M7 的一次性批处理不同，
M8 是**有状态的到车流水**，数据落在独立的 `grading.sqlite`，重启后保留。

- 定等口径开秤前在合同里选定：`worst_point`（抽样点取最差水分/杂质，仓里口径）或
  `composite`（全部抽样点算术平均，农户口径）。结论同时保存采信值、全部抽样点与判定依据，分歧可逐条复核。
- **同一份可复核结论**：车号、仓号、抽样点、采信水杂、等级、等级单价、净粮/干物质/折标量、
  未舍入金额、到分应付、化验指纹、结论号在同一条追加记录里；金额全程 Decimal，舍入只在应付末端。
- **同化验重试不重复计价**：抽样点规范化指纹一致时幂等返回原结论，不新增版本、不产生第二笔应付。
- **已开应付不可悄悄改写**：接受入仓即锁单，新化验返回 `409 PAYABLE_LOCKED`，更正须走红冲调整。
- **待复验与复检**：超收购上限或落不进等级带的车进待复验队列；复检生成新版本结论并通过
  `supersedes` 作废旧结论（旧记录保留不删），复检通过才入仓参与混仓。
- **混仓与余量**：按在仓车净粮量加权重算仓批水杂与等级，首车 `BIN_MIX_OPEN`、等级维持 `BIN_MIX`、
  后到车拉低等级 `BIN_MIX_INVALID`（原仓批定等失效留痕）；仓批余量=容量−在仓净重，待复验车不占仓。
- 边界：禁止跨粮种混仓；不处理税费与付款；复验只能换化验，不能改仓号或净重。

主要接口：`POST /api/grading/contracts`、`POST /api/grading/bins`、
`POST /api/grading/trucks/arrive`、`POST /api/grading/trucks/recheck`、
`GET /api/grading/batches/<合同号>`（本批逐车结论+仓批+待复验）、
`GET /api/grading/bins/<仓号>`、`GET /api/grading/pending`、`GET /api/grading/ledger`。

## 演示与复核

1. 运行默认样例，核查隔离原因与业务合计。
2. 修改CSV单元格或参数并重跑，保留行号与输入摘要。
3. 在最后一步复核，旧版本提交返回409。
4. 证据CSV包含采信行和隔离行，重跑相同内容复用批次。

## 数据与目录

`app/modules/` 按业务切分；`sample_data/` 为UTF-8 BOM、GB18030及干净/脏样例；`tests/` 含规则与端到端测试。SQLite保存运行与复核，命名卷records保留重启后的记录。若需从头开始，可先停止服务并在确认不再需要记录后删除该项目records卷。

## 定义与边界

单一粮种，标准水分和单价由批次参数给出。不处理跨粮种价差、税费和在线地磅接入。4MB文件上限。

详细字段、计算定义与原因码见 `docs/DATA-DICTIONARY.md`，回归证据见 `docs/DEPTH.md`。
